# OpenHinoVoice v0.5.0

Windows x64向けの日本語音声入力アプリです。音声認識はPC内で行います。exeにコード署名はありません。

## 主な変更

- 発話を区切って認識し、確定した文と話している途中の仮の文を字幕に表示します。
- 選択した文章を音声の指示で書き換えるEditモードを追加しました。選択はUI AutomationのTextPatternで読み、Ctrl+Cは送りません。
- OpenAI互換のローカルLLM、Anthropicなどの接続先、オフライン設定を追加しました。
- 設定画面を整理し、初回設定の案内、モデル取得の進捗、マイクの確認、音と表示のプリセットを追加しました。
- キー入力、認識worker、履歴保存、クリップボードの復元を整理しました。設定画面は引き続き別プロセスです。
- v0.1.3の貼り付けと直近の文章を回収する機能を継承しました。クリップボードの自己競合と復元時のデータ消失、空の字幕によるクラッシュ、HTTPエラー文のUnicodeによるクラッシュを修正しました。
- 貼り付け待ちの間に予約した録音も、通常の録音開始と同じEdit判定を通るようにしました。Edit中には使えないEnter操作を案内しません。
- 取り消しの操作が先に届いた場合、保留中の文章を貼り付けないようにしました。
- クリップボードの復元時に別アプリが使用中の場合は、元の内容を保持して再試行します。後からコピーされた内容は上書きしません。

## 更新と診断

既存の設定を読み込めます。設定と以前のexeを保持して更新してください。

診断用の`usage_log`は既定オフです。有効にすると状態、待ち時間、エラーをPC内へ記録します。音声は含めず、外部へ送信しません。既に明示した設定値は維持します。

## 検証範囲

公開用exeはGitHub ActionsのFull検証と、実Windowsクリップボードおよび別プロセスの入力欄への貼り付け検証を通した成果物です。録音開始キーとEnterを送信し、入力先の本文、二重入力がないこと、元のクリップボードの復元、新しいコピーの保持を確認します。この試験ではPCMと認識応答にfixtureを使います。

実マイクの品質、個々のアプリのEdit対応、各クラウドAPI、複数のローカルLLM、長時間録音の性能は別の確認が必要です。入力先やPCの状態によって待ち時間は変わります。

`SHA256SUMS.txt`で配布ファイルを照合できます。`build.json`にはコミット、ビルド条件、必須検証の結果を、`verification.json`にはFull検証の範囲と件数を記録しています。
